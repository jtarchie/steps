Read a UTF-8 text file's contents, given a path relative to the step's working directory. Optionally pass start_line and/or end_line (1-indexed, inclusive) to read only a slice of a large file instead of its capped prefix — useful both for a file too big to read in one call and for output any tool spilled to a file when it exceeded the inline size limit (run_shell, an MCP tool, a sub-agent's answer, previous_run, ...) — see that tool's own result for the exact path.
