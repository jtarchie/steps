# examples/

`examples/*.yml` are runnable, self-contained example pipelines, one per feature area (several self-verifying via `steps test`). `TestExamplesRun` runs every one of them and is **opt-out**: a file that needs something the test host hasn't got says so in a `# steps-test: skip -- <reason>` marker on its first line (a live model, the `claude` CLI, a docker daemon or real API, the network, or a verdict-dependent outcome that could never be a deterministic fixture). `pr-review.yml`'s shape is instead pinned deterministically by `e2e_pr_review_test.go` against the fake provider. Opt-out is deliberate: an unmarked example that does not run is a failure, which is how a shipped example calling `make build` in a repo with no Makefile was caught. Agent examples take their model from `defaults.model`, overridable with `$STEPS_MODEL`.

**`examples/invalid/*.yml` is the inverse**: pipelines that must FAIL `LoadConfig`, each with a `# expect: <substring>` line naming the error it has to produce (`examples_invalid_test.go`). That is where a load-time rejection gets a readable file; the four `examples/*.yml` globs are non-recursive precisely so these stay out of them.
