# tools/kindswitch

The `go/analysis` pass in the root CLAUDE.md's validation sequence. Step-kind dispatch is checked by golangci-lint's `exhaustive` (default does NOT signify exhaustive), which only sees the tagged spelling `switch kind, _ := s.Kind(); kind`. This pass is the guard that keeps it that way: it reports any tagless switch whose case expressions read a struct field tagged `kind:"..."` (config.Step's kind fields). A new kind field takes the tag; a new kind constant needs nothing here. A site handling a subset lists the remaining kinds in an empty case rather than leaning on `default:`, so the next kind is reported there too. `//kindswitch:ignore <reason>` exists for a genuine exception; no kind-dispatch site uses it. Fixtures live in `testdata/`.
